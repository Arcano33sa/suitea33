    Respaldo

    JSON local

    Exporta o importa respaldos completos de la Suite A33. También puedes generar e importar JSON personalizados por módulos, submódulos y eventos POS sin borrar datos no incluidos.

    Última descarga de respaldo solicitada

    Exportar una copia

    Guarda toda la Suite o selecciona los módulos y eventos que necesitas.

    Importar un respaldo

    Revisa el archivo y las advertencias antes de confirmar. Exporta una copia de los datos actuales primero.

    Diagnóstico de almacenamiento

    Consulta disponibilidad, registros y cuota estimada sin modificar datos.

    Revisar productos

    Consulta el estado del catálogo. Las acciones de inactivar y eliminar requieren confirmación.

    Qué hace

    Incluye los datos de la Suite disponibles en este navegador, en el formato de respaldo existente.

    Qué no cambia

    El respaldo completo conserva su formato histórico; el personalizado se identifica como parcial.

    Cuidado

    Al importar un respaldo completo se reemplazan los bloques incluidos; los ausentes se conservan. Un respaldo parcial fusiona las secciones incluidas. Exporta una copia antes de importar.

    JSON importados

    Registro compacto de los últimos respaldos importados en este navegador.

    Respaldo

    Operación segura

    Operativo
    • Exporta respaldo JSON completo.
    • Exporta JSON personalizado por módulos y submódulos.
    • Importa respaldos completos o parciales desde este navegador.
    • Mantiene el formato histórico del archivo completo.
    • Conserva lectura clara en desktop e iPad.
